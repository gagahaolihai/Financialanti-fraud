## 一、声明

本项目「反诈卫士 v3.0」为项目组**独立开发**的原创软件作品，代码、知识库、文档均为自行设计与实现，未抄袭任何现有软件。经检索（详见《软件查重报告.md》），本项目在**功能方向**上与现有反诈产品存在共性——**反诈属公共安全领域，技术方向趋同属行业正常现象**——但在**技术实现路径、算法组合、交互设计**上具有独立设计。以下逐项说明与最接近在先技术的区别。

## 二、与最接近在先技术的区别

### 2.1 区别于 CN118113875A《一种文本诈骗意图识别方法》

| 对比项 | CN118113875A | 本项目 |
|---|---|---|
| 识别目标 | 诈骗 / 非诈骗**二分类** | **多意图路由**（12 类意图）+ **16 类诈骗细分** + **5 级风险分级** |
| 技术路径 | 诈骗词汇模式库（正则）+ 搜索模型在话术库算相似度 | **零样本语义锚点分类**（无需标注）+ 规则置信度**门控融合**（规则证据充分时语义需 ≥0.7 才可覆盖） |
| 误报控制 | 未涉及 | 独创**知识查询门控**：识别为知识/法律咨询类意图时，仅保留行为类风险规则，避免知识提问被误判为高危 |
| 对话状态 | 单句识别 | **跨轮时序累积**（见 3.1） |

**核心区别**：该专利解决"是不是诈骗"，本项目解决"是什么意图 + 多危险 + 该怎么办"，且引入该专利未涉及的**意图门控**与**时序累积**机制。

### 2.2 区别于 CN118535987A《一种基于诈骗阶段和要素的诈骗类型判断方法》

| 对比项 | CN118535987A | 本项目 |
|---|---|---|
| 输入方式 | 用户按系统提示**分步补全细节** | **单轮自然语言**即完成意图 + 风险 + 类型判断 |
| 判定方法 | 三阶段六要素 + 机器学习诊断模型 | 零样本语义锚点 + 规则风险计分 |
| 风险刻画 | 诈骗阶段划分 | **跨轮时序风险累积** + 可解释触发规则 |

### 2.3 区别于 CN121387239A《一种基于多模态检测与 LSTM 模型的适老化反诈智护系统》

| 对比项 | CN121387239A | 本项目 |
|---|---|---|
| 主检测对象 | 屏幕视频流 / Deepfake（CNN+LSTM+频率域，H.264 逐帧） | **文本对话 + 诈骗截图 OCR + 语音话术转写** |
| 系统定位 | **被动实时监测**（智护） | **主动对话劝阻**（用户提问 → 研判 → 劝阻） |
| 隐私处理 | 未涉及 | 独创 **PII 本地检测 + AES-256-GCM 加密脱敏链路**，语义模型零联网 |
| 适老化实现 | 适老化界面 + 学习社区 | **人文关怀状态机**：自动识别老年人/困惑/恐惧并动态调整表达 |

## 三、本项目的原创设计点

1. **时序累积风险研判**：`score = Σ当前规则 + 0.5×历史 + 0.1×近5分钟`，捕捉渐进式诱导话术，避免单句误判；输出**风险等级 + 触发规则 + 处置建议**，结果完全可解释、可追溯。
2. **知识查询门控**：区分「知识咨询」与「实施行为」两类意图，对知识/法律类提问仅保留行为类规则计分，显著降低知识类提问的误报（实测误报清零）。
3. **零样本语义锚点意图分类**：基于 384 维多语言向量锚点平均相似度，**无需标注数据**即可扩展意图类别，新增诈骗类型成本极低。
4. **隐私优先架构**：PII（手机号/身份证/银行卡）实时检测 + AES-256-GCM 加密脱敏，语义模型**本地零联网**推理，从架构上杜绝隐私外泄。
5. **人文关怀状态机**：识别老年人、困惑、恐惧等状态，动态调整语言表达（简化、安抚、适老模式）。
6. **三模混合路由**：规则引擎 / 语义模型 / RAG 大模型按置信度智能切换，任一环节缺失自动降级，保证任何环境下服务不中断。

## 五、结论

本项目与现有反诈软件在**功能方向上存在行业共性**，但在**意图识别路径、风险研判机制、隐私保护链路、人文关怀设计**四个维度具有独立、可辨识的原创设计，**不构成对任何在先软件代码的抄袭，亦不实施任何在先专利的技术方案**。
