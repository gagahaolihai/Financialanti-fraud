## 二、本项目技术画像

### 2.1 基本信息

| 项 | 内容 |
|---|---|
| 软件全称 | 反诈卫士（多模态智能反诈对话系统） |
| 版本 | v3.0 |
| 定位 | 面向普通公众（重点：老年人、学生）的自然语言反诈对话与劝阻系统 |
| 技术栈 | Python 3.11 / Flask / sentence-transformers / FAISS / RAG(LLM) / EasyOCR |
| 参赛 | 第八届全球校园人工智能算法精英大赛 · 赛题二「AI+软件创新」 |

### 2.2 核心能力（比对基准）

1. **智能识别**：语义向量 + 规则引擎双模，识别 16 类常见诈骗；
2. **风险研判**：多维度风险规则 + 时序累积，输出 5 级风险等级；
3. **RAG 增强**：知识库检索结果注入大模型，生成有依据的回复；
4. **多模态检测**：诈骗截图 OCR 特征检测 + 语音话术特征检测；
5. **情景模拟训练**：12 个诈骗剧本，多轮人机对抗；
6. **人文关怀**：老年人模式、困惑简化、恐惧安抚；
7. **隐私优先**：PII 自动检测 + AES-256-GCM 加密脱敏，本地模型零联网。

### 2.3 项目自述的 5 项创新点

1. 规则 + 语义 + RAG **三模混合路由**（按意图置信度智能选引擎）；
2. **隐私优先架构**（本地零联网推理 + PII 加密脱敏）；
3. **多模态反诈**（截图 / 语音特征检测）；
4. **人文关怀机制**（自动识别老年人 / 困惑 / 恐惧状态并调整表达）；
5. **可解释风险研判**（风险等级 + 触发规则 + 处置建议可追溯）。

> 下文比对即以 §2.2 的 7 项能力、§2.3 的 5 项创新点逐一对照在先专利。

### 3.1 高风险专利（技术方案实质重合）

#### ⚠️ H1 · CN118113875A《一种文本诈骗意图识别方法、装置、设备和存储介质》

| 项 | 内容 |
|---|---|
| 申请人 | 广州趣研网络科技有限公司 |
| 申请日 | 2024-03-25 |
| 法律状态 | 实审中（Pending） |
| 来源 | https://patents.google.com/patent/CN118113875A/zh |

**独立权利要求 1 要点**（原文归纳）：

1. 对用户输入文本做预处理，得到待识别文本；
2. 通过**诈骗词汇模式库中的规则表达式**识别是否存在诈骗特征词汇 → **第一识别结果**；
3. 将待识别文本输入**搜索模型**，在**诈骗话术模型库**中搜索相似度值 → **第二识别结果**；
4. 根据第一、第二识别结果**融合**输出最终识别结果。

**与本项目的重合**：

| 本项目的实现 | 该专利权利要求 |
|---|---|
| `IntentRecognizer.recognize()` 规则层：关键词/正则加权计分 | 诈骗词汇模式库 + 规则表达式 → 第一识别结果 |
| `SemanticIntentClassifier`：384 维向量余弦相似度取最高 | 搜索模型 + 诈骗话术模型库算相似度 → 第二识别结果 |
| `recognize_enhanced()`：规则置信度 ≥0.7 直接返回，否则语义融合 | 根据第一、第二识别结果融合输出 |

**判定**：本项目最核心的「规则 + 语义双模意图识别」与该专利独立权利要求 1 **在步骤构成上几乎逐一对应**，属**实质重合**。若本项目就该点申请发明专利，权利要求 1 极可能因**缺乏新颖性/创造性**被驳回。

**权利要求要点**：

## 四、软件著作权查重结果

### 4.1 关键前提：软著保护什么

> 计算机软件著作权**只保护代码、文档等表达形式，不保护功能、算法思想**（《计算机软件保护条例》）。因此，**功能与他人软件相同，不构成软著侵权**；软著查重的真正风险只有两条：**① 代码抄袭；② 软件名称与他人已登记软件完全相同**（登记时会被要求区分）。

### 4.2 同名 / 近名情况

## 六、结论与建议

### 6.1 申请软件著作权 —— 建议做，先改名

- **结论**：代码原创，**登记无障碍**，是本项目最稳妥的知识产权保护方式。
- **改名建议**（任选，核心是加限定词以区分）：
  - 反诈卫士·校园版 / 反诈卫士（AI 对话劝阻系统）
  - 「慧眼反诈」对话劝阻系统
  - 「守钱袋」智能反诈助手
- 登记名称建议同时体现**技术特征**（如"多模态智能反诈对话系统"），既利于区分，也利于维权。

### 6.2 申请专利 —— 风险高，需差异化规避

若确需申请发明专利，**不能直接照搬现有方案**，建议做以下**规避设计**（择一或组合）：

| 方向 | 做法 | 依据 |
|---|---|---|
| **A. 重构权利要求客体** | 放弃"规则+语义双模识别"作为独立权利要求，改以**"时序累积风险研判"**为核心：`score = Σ当前规则 + 0.5×历史 + 0.1×近5分钟`，配合"知识查询门控"（知识类意图仅保留行为规则） | 规避 H1 的"词汇模式库+搜索模型"表述；时序累积与门控未见于 H1 |
| **B. 聚焦组合创新** | 以「**隐私脱敏 → 意图识别 → 时序风险 → RAG 生成**」的**完整链路**为权利要求，突出 PII 本地加密 + 零联网这一差异化 | H1/H3 均未涉及 PII 加密脱敏链路 |
| **C. 转向实用新型/外观** | 若产品含硬件交互（如适老终端），可考虑实用新型 | 避开发明专利的创造性审查 |
| **D. 放弃专利，用软著 + 论文/竞赛成果保护** | 对参赛项目而言性价比最高 | 发明专利授权周期长（2-3 年），竞赛无需专利 |

> **强烈建议**：正式申请前，委托专利代理机构就 **CN118113875A** 做一次针对性**新颖性检索 + FTO 分析**，本报告可作为初步输入。
