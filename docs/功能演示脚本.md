# 反诈卫士 v3.0 — 功能演示视频脚本

> 用途：赛题二「AI+软件创新」提交材料之**功能演示视频**
> 目标时长：3–4 分钟 ｜ 分辨率：1920×1080 ｜ 需配**中文字幕**
> 已有素材：`voice/` 目录 10 段配音 mp3、`record_real_demo.py`（真实录屏）、`merge_audio_video.py`（音视频合成）

---

## 一、演示总原则

1. **先结论后过程**：每个功能先展示"用户输入 → AI 输出"的完整闭环，不要只截静态页面。
2. **突出 AI**：评委看的是"AI 与软件融合"，所以语义识别、风险研判、RAG 回复必须给特写、给对照。
3. **真实可复现**：用真实输入（口语化描述），避免明显"托"的样例。
4. **字幕必备**：无字幕的演示视频在评审中非常吃亏。

## 三、录制步骤

1. **准备环境**
   ```bash
   cd 升级版反诈app
   python run.py          # 启动服务，确认 http://localhost:5000 正常
   ```
2. **确认功能可用**：访问 `/api/health`，确认 `nlp_semantic`、`rag_engine` 为 `true`（AI 依赖已安装）。
3. **录制**：使用 `record_real_demo.py` 或 OBS Studio（推荐 OBS，1080p / 30fps）。
   - 提前把演示用的输入文本准备好，逐条粘贴，避免打字卡顿。
   - 每个功能录制 2–3 个 take，后期挑最顺的。
4. **配音对齐**：按分镜表把 `voice/*.mp3` 与画面时间轴对齐；实时解说部分可后期补录或用字幕替代。

---

## 四、合成步骤

```bash
# 按 merge_audio_video.py 的用法合成配音与录屏
python merge_audio_video.py
```

- 若脚本参数不符，可直接用剪辑软件（剪映 / Premiere）：
  1. 导入录屏 + 各段配音
  2. 按分镜表对齐时间轴
  3. 加中文字幕（剪映"识别字幕"可自动生成后校对）
  4. 导出 1080p MP4
