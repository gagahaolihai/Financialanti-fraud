# 反诈卫士 v3.0 — 部署指南

> 面向赛题提交的「运行环境与部署方式」说明，含本地 / Docker / 云服务器三种方案。

---

## 一、环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows / Linux / macOS |
| Python | 3.11.x |
| 内存 | ≥ 4 GB（语义模型约 500 MB） |
| 磁盘 | 核心依赖约 1.5 GB（含 torch）；多模态另需约 500 MB |
| 网络 | 首次安装依赖需要；运行时可完全离线 |

---

## 二、方案一：本地部署（演示推荐）

```bash
cd 升级版反诈app

# 1. 创建虚拟环境
python -m venv .venv
# Windows:  .venv\Scripts\activate
# Linux/macOS:  source .venv/bin/activate

# 2. 安装依赖
pip install -r requirements.txt            # 核心（含语义 NLP）
pip install -r requirements-extra.txt      # 可选（多模态 + 文档生成）

# 3. 配置环境变量
cp .env.example .env                       # Windows: copy .env.example .env

# 4. 启动
python run.py                              # 自动打开浏览器
# 或
python -m flask --app app run --port 5000
```

访问入口：

| 入口 | 地址 |
|---|---|
| 对话主界面 | http://localhost:5000 |
| 管理后台 | http://localhost:5000/admin |
| API 文档 | http://localhost:5000/api/docs/ui |
| 健康检查 | http://localhost:5000/api/health |

**验证是否成功**：访问 `/api/health`，确认 `nlp_semantic` 与 `multimodal_ocr` 均为 `true`。

## 三、方案二：Docker 部署

```bash
docker-compose up -d          # 构建并启动
docker-compose logs -f        # 查看日志
docker-compose down           # 停止
```

配合 `nginx.conf` 做反向代理；生产环境建议开启 HTTPS（`.env` 中设 `HTTPS_ONLY=true` 并配置证书）。

---

## 四、方案三：云服务器部署（生产）

```bash
# 1. 服务器安装 Python 3.11 与依赖
pip install -r requirements.txt

# 2. 用 Gunicorn 启动（多进程）
gunicorn -w 4 -k gthread --threads 4 -b 127.0.0.1:5000 app:app

# 3. Nginx 反向代理（示例）
server {
    listen 80;
    server_name your-domain.com;
    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

**注意**：语义模型首次加载约 10 秒，建议服务启动后预热一次，避免首个请求超时。

## 五、环境变量（关键项）

| 变量 | 说明 | 默认 |
|---|---|---|
| `PORT` | 服务端口 | 5000 |
| `LLM_ENABLED` | 是否启用大模型 | false |
| `LLM_API_KEY` | 大模型 Key（不填则用规则引擎） | — |
| `NLP_OFFLINE_MODE` | 使用本地模型，不联网 | true |
| `SAFE_MODE` | 纯规则引擎兜底 | false |
| `HTTPS_ONLY` | 强制 HTTPS | false |
| `DATA_RETENTION_DAYS` | 数据保留天数 | 90 |

完整配置见 `.env.example`。

## 六、三档运行模式

| 模式 | 条件 | 能力 |
|---|---|---|
| 完整模式 | 装齐依赖 + LLM Key | 语义 NLP + 向量检索 + RAG + 多模态 |

## 七、常见问题

**Q1：安装 `easyocr` 时 `shapely` 编译报错？**
国内镜像可能缺预编译包，先单独安装：
```bash
pip install shapely -i https://pypi.org/simple/
```

**Q2：pip 安装过程中断（提示无法删除文件）？**
在部分受限环境中，文件删除操作可能被拦截。可设置环境变量后重试：
```bash
CODEBUDDY_SAFE_DELETE_ENABLED=0 pip install -r requirements.txt
```

**Q3：venv 中升级 setuptools 报错（找不到 pkg_resources）？**
创建 venv 后先手动清理自带 setuptools，再安装依赖：
```bash
rm -rf .venv/Lib/site-packages/setuptools* .venv/Lib/site-packages/pkg_resources*
```

**Q4：语义检索不生效？**
确认已装 `sentence-transformers` + `faiss-cpu`，且 `models/paraphrase-multilingual-MiniLM-L12-v2/` 完整；用 `/api/health` 查看 `nlp_semantic`。

**Q5：中文路径下 OCR 读图失败？**
已在 v3.0 修复（改为 PIL 读图再传 OCR），确保使用最新代码。

**Q6：多模态首次运行很慢？**
easyocr 首次会下载 OCR 模型（约 100 MB），属正常现象，之后走本地缓存。
