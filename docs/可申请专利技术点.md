## 三、逐点详述

### ⭐⭐⭐ A. 基于意图门控的风险研判方法（强推荐）

**技术方案**

对用户输入先做意图分类，得到意图类别；当意图属于**知识咨询类**（知识查询 / 反诈咨询 / 法律咨询）时，风险研判**仅启用行为类规则白名单**，屏蔽全部描述性规则；其余意图则启用全部规则。白名单示例（7 条）：

```
转账到陌生账户 / 提供验证码 / 屏幕共享 / 提供身份证照片 /
被要求转账 / 点击不明链接 / 下载不明APP
```

**解决的技术问题**

现有反诈系统把"用户**描述**诈骗"与"用户**正在**被骗"混为一谈——用户问"刷单返利是什么"会被误判为高危。本方法通过意图门控区分二者。

**与在先技术的区别**

| 对比对象 | 区别 |
|---|---|
| CN118113875A | 该专利只做"诈骗/非诈骗"二分类，**无意图类别概念**，更无按意图开关规则 |
| CN117455498A（M2） | 该专利的风险评估模型输入是预警数据，**不涉及用户意图** |
| 其余全部专利 | 未检索到任何"按意图类别门控风险规则"的方案 |

**权利要求方向（独立权利要求要点）**

> 一种对话式反诈的风险研判方法，其特征在于：获取用户输入并识别其意图类别；判断所述意图类别是否属于预设的知识咨询类集合；若是，则在风险规则库中仅选取行为类规则子集进行匹配计分；若否，则选取全部风险规则进行匹配计分；根据计分结果输出风险等级。

**专利性评估：高**。该机制在检索范围内**独一无二**，且解决明确的技术问题（误报），具备新颖性与创造性。

---

### ⭐⭐⭐ B. 对话式反诈中的敏感信息检测—加密脱敏—反向告警方法（强推荐）

**技术方案**

1. **会话级密钥派生**：`session_key = SHA256(master_key : session_id : random)`，每会话独立；
2. **PII 检测与替换**：识别手机号/身份证/银行卡/验证码/密码/姓名/地址等 9 类，原文加密后以 **token→密文** 存入会话，正文替换为**掩码**，后续语义/大模型引擎**只接触掩码文本**；
3. **PII 与反诈信号联动**：当检测到用户**主动说出验证码、银行卡密码**等，不仅脱敏，还将其**作为反诈高危信号**触发风险提示（因正常场景下用户不会自述这些）；
4. **差异化反向告警**：按 PII 类型生成不同话术（如"验证码等同于账户钥匙，任何情况下不要告诉他人，包括'客服'和'警察'"）；
5. **会话关闭擦除**：会话结束时销毁密钥与 PII 存储。

**解决的技术问题**

现有反诈对话系统要么不处理用户隐私（直接把含身份证的原文送进模型/日志），要么只做静态脱敏，未把"隐私保护"与"反诈研判"打通。

**与在先技术的区别**

- CN121387239A（H3）仅提"适老化智护"，**无任何 PII 处理**；
- 检索范围内**未见**任何反诈系统的 PII 检测 + 会话级加密 + 反向告警方案。

**权利要求方向（独立权利要求要点）**

> 一种对话式反诈中的用户信息保护方法，其特征在于：为每个会话派生独立密钥；检测用户输入中的敏感信息并加密存储、以掩码替换后送入下游引擎；当检测到预设的高危敏感信息类型时，同步生成风险提示；会话结束时销毁密钥与加密数据。

**专利性评估：高**。与全部在先专利差异最大，**最有可能授权**，建议优先申请。

---

### ⭐⭐ C. 规则证据强度门控的双模意图融合方法

**技术方案**

规则层（关键词/正则加权计分）与语义层（向量相似度）融合时：

- 若规则层命中**显式关键词证据**，则视为高精度判断，**语义层需达到阈值（≥0.7）才允许覆盖**规则判定；
- 若规则层无命中证据，则允许语义层主导；
- 语义层未达覆盖阈值但 >0.4 时，记为"混合模式"并保留语义参考值。

**解决的技术问题**

规则层置信度公式天然偏低（匹配数 ÷ 关键词总数 × 系数），若简单"谁高谁赢"，会导致规则层**正确判定被语义层误覆盖**（实测：用户问"给我讲讲刷单返利诈骗"被覆盖为 emergency）。

**与在先技术的区别**

- CN118113875A 权利要求 1 第 4 步仅"根据第一、第二识别结果输出最终结果"，属**无门控的简单融合**；
- 本方法引入**"证据强度 → 覆盖阈值"的动态门控**，未见于在先专利。

**专利性评估：中高**。区别点明确，但"融合+阈值"属较易被认定为常规技术手段的范畴，需在从属权利要求中补充具体阈值策略以增强创造性。

---

### ⭐⭐ D. 用户情绪状态识别与响应策略自适应方法

**技术方案**

在意图识别之外，识别三类**情绪/身份状态**并映射到不同响应策略：

| 状态 | 触发 | 响应策略 |
|---|---|---|
| `confusion`（困惑） | "不懂/不理解/没明白" | 用简单语言重新解释 |
| `fear_anxiety`（恐惧焦虑） | 恐惧/紧张表述 | **先安抚情绪，再给行动指引** |
| `elderly_identity`（老年人） | "我老了/年纪大了/老年人" | 适老化表达（短句、耐心、口语） |

策略与**风险等级**联动：高风险 + 恐惧时，优先安抚再引导报警。

**与在先技术的区别**

- H3 有"适老化"，但为界面/学习社区层面，**无"情绪状态 → 响应策略"映射**；
- M6/M8 有情绪识别，但用于计算"易骗风险等级/得分"，**不用于生成响应**。

**专利性评估：中**。"情绪识别 + 响应策略生成"的组合具备新颖性，可申请。

### ⭐ E. 对话时序累积风险评分方法

**技术方案**

```
score = Σ w_rule(当前命中) + Σ 0.5·w_rule(历史命中) + Σ 0.1·score(近5分钟)
风险等级：≥2.0 极高 | ≥1.0 高 | ≥0.4 中 | >0 低
```

即：单句判分叠加**对话历史命中（权重 0.5）**与**近 5 分钟风险事件衰减（权重 0.1）**，捕捉**渐进式诱导**（骗子往往分多轮逐步诱导）。

**与在先技术的区别**

- M2（CN117455498A）为"预警数据 → 风险评估模型 → 风险等级"，**无跨轮对话的时序累积与权重衰减**；
- H1 为单句识别，无跨轮状态。

**专利性评估：中**。"时序衰减累积"在风控领域有一定先例，建议与 A（门控）**组合**成一件申请以增强创造性。

---

### ⭐ F. 多模态诈骗证据特征分类检测方法

**技术方案**

- **截图**：OCR 提取文字后，按 5 类场景特征分类检测——假法律文书（通缉令/逮捕令/案件编号）、可疑 APP（屏幕共享/远程协助类）、虚假客服（退款理赔/关闭百万保障）、虚假投资（日收益/稳赚不赔）、可疑链接/二维码；
- **语音**：音频转写后匹配冒充公检法、刷单兼职、虚假投资、心理操控等话术特征。

**与在先技术的区别**

- M 系列有大量"诈骗网站截图识别"专利（如 CN114005004B、CN111368838A），但对象是**网站页面**；
- 本项目对象是**用户上传的聊天/短信/APP 界面截图**，场景特征不同，但**边界较近，易被审查员引证**。

**专利性评估：中低**。建议**不单独申请**，可作为 A/B 组合申请中的从属权利要求。

| 三档降级架构（完整/本地智能/规则兜底） | 属工程实现，缺乏技术方案层面的创造性 |
| 诈骗类型知识库结构（16 类要素模型） | 属数据/信息组织，专利保护弱，宜走**软著** |
| 情景模拟 + 游戏化 | 已被 M6–M9 多件专利覆盖 |
| 规则 + 语义双模识别 | 已被 CN118113875A 覆盖 |

## 五、申请策略建议

### 策略一（推荐）：优先申请 B，最稳

- **《一种对话式反诈中的用户信息检测、脱敏与告警方法》**
- 与全部在先专利差异最大，**授权概率最高**；
- 独立权利要求 1 以"会话级密钥 + 掩码替换 + 高危 PII 联动 + 会话擦除"为必要技术特征。

### 策略二：A + E + C 组合申请，价值最高

- **《一种基于意图门控与时序累积的对话式反诈风险研判方法及系统》**
- **独立权利要求 1 以 A（意图门控）为核心**（最独特），E（时序累积）、C（门控融合）作为从属权利要求；
- 这样可**绕开 CN118113875A**——因 H1 的核心是"词汇模式库 + 搜索模型"，而本申请的独立权利要求不包含该特征组合。

### 策略三：时间与成本考量

| 事项 | 建议 |
|---|---|
| 申请类型 | 发明专利（保护期 20 年，审查严）；若急于授权可先申实用新型（不适用方法专利，需转产品形态） |
| 申请时机 | **先申请再公开**（竞赛展示/论文发表会破坏新颖性，务必在公开前提交） |
| 代理机构 | 正式申请前，建议委托代理机构就 **CN118113875A** 复核本方案的新颖性，本报告可作为输入 |
| 性价比 | 对竞赛项目，**软著 + 1 件发明专利（B）** 是较优组合 |
