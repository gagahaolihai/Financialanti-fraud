## 二、在线演示地址

### 第 0 步：本地先跑通（两种方案都以此为前提）

```bash
cd 升级版反诈app
.venv/Scripts/python.exe app.py          # Windows
# 或  python run.py
```

浏览器访问 `http://localhost:5000`，并确认：

```bash
curl http://localhost:5000/api/health
```

要求 `status=ok`、`nlp_semantic=true`、`multimodal_ocr=true`。任一为 `false` 说明 AI 依赖没装齐，先按 `docs/部署指南.md` 第七章排查。

---

### 方案 A：内网穿透（推荐，最快，适合学生应急）

把本机 5000 端口映射到一个公网地址，5–10 分钟搞定。

**以 cpolar 为例：**

```bash
# 1. 官网注册后下载安装，配置 token
cpolar authtoken <你的token>

# 2. 映射本地 5000 端口
cpolar http 5000

# 3. 终端会打印公网地址，形如：
#    https://xxxxxxxx.cpolar.cn  →  写入提交材料
```

**以 ngrok 为例：**

```bash
ngrok config add-authtoken <你的token>
ngrok http 5000
```

| 优点 | 缺点 |
|---|---|
| 零成本、零运维、5 分钟出地址 | 本机关机/断网即失效；免费版地址重启后会变 |

> ⚠️ 提交前务必**固定住地址**（重启穿透服务前先截图确认），并在提交材料里写清"演示时段"。若赛方可能在你关机时访问，此方案不可靠。

---

### 方案 B：云服务器（推荐用于正式提交）

**选型**：阿里云 / 腾讯云「学生优惠」轻量应用服务器（约 10 元/月，2 核 4G 起）。
> 内存低于 4G 会因 torch + easyocr 占用过高而 OOM，务必 4G 起。

```bash
# 1. 服务器装环境（以 Ubuntu 22.04 为例）
sudo apt update
sudo apt install -y python3.11 python3.11-venv nginx

# 2. 上传项目（git clone 或 scp 压缩包）
cd 升级版反诈app

# 3. 建虚拟环境 + 装依赖
python3.11 -m venv .venv
source .venv/bin/activate

# ★ 关键：装 CPU 版 torch，避免拖入 2GB+ 的 CUDA 依赖
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt

# 4. 后台启动（Gunicorn）
nohup gunicorn -w 2 -k gthread --threads 4 -b 127.0.0.1:5000 app:app \
  > logs/gunicorn.log 2>&1 &

# 5. 预热一次，避免首个请求超时（模型首次加载约 10s）
curl http://127.0.0.1:5000/api/health
```

Nginx 反向代理配置见 `docs/部署指南.md` 第四节。安全组需放行 80/443。

| 优点 | 缺点 |
|---|---|
| 长期稳定、地址固定、可配 HTTPS | 需 1–2 小时配置，有少量成本 |

---

### 方案 C：容器平台（Render / Railway / HuggingFace Spaces）

直接用现有 `Dockerfile`：

```bash
docker-compose up -d      # 本地先验证镜像能起
```

平台侧指定用 `Dockerfile` 构建即可。**注意**：镜像含 torch + easyocr，体积约 2GB，免费额度下构建可能超时或超限，不优先推荐。

---

### 取舍建议

| 方案 | 出地址耗时 | 稳定性 | 成本 | 适合场景 |
|---|---|---|---|---|
| A 内网穿透 | 5–10 分钟 | 低（本机依赖） | 免费 | 赶时间、内部预览 |
| **B 云服务器** | 1–2 小时 | **高** | ~10 元/月 | **正式提交（推荐）** |
| C 容器平台 | 30–60 分钟 | 中 | 免费额度 | 有 Docker 经验 |

**结论**：正式提交走 **B**；若提交窗口临近来不及，先用 **A** 顶住，再补 B。

## 三、功能演示视频

分镜、旁白、演示输入文本见 `docs/功能演示脚本.md`。以下是落地步骤：

### 1. 准备

```bash
cd 升级版反诈app
.venv/Scripts/python.exe app.py
curl http://localhost:5000/api/health     # 确认 nlp_semantic / multimodal_ocr 为 true
```

- 浏览器缩放 100%，关掉无关标签页与系统通知
- 把 `docs/功能演示脚本.md` 第六节的 6 条演示文本复制到记事本，录制时逐条粘贴（别现场打字）

### 2. 录制

- 工具：OBS Studio（1080p / 30fps）或项目自带 `record_real_demo.py`
- 每个功能录 2–3 个 take，后期挑最顺的
- **重点给特写**：语义识别、风险研判、RAG 回复、隐私脱敏（`138****5678`）

### 3. 配音与合成

```bash
python merge_audio_video.py
```

若脚本参数不符，改用剪映 / Premiere：

1. 导入录屏 + `voice/*.mp3`
2. 按分镜表对齐时间轴
3. 用"识别字幕"自动生成中文字幕，**逐条校对**（字幕错误很扣分）
4. 导出 1080p MP4

### 4. 导出规范

| 项 | 要求 |
|---|---|
| 分辨率 | 1920×1080 |
| 格式 / 编码 | MP4 / H.264 |
| 时长 | 3–4 分钟 |
| 字幕 | 中文字幕（必备） |
| 命名 | `反诈卫士_功能演示_团队名.mp4` |

## 五、常见坑

| 坑 | 处理 |
|---|---|
| 服务器上 torch 装了 CUDA 版，多占 2GB+ | 用 CPU 版：`pip install torch --index-url https://download.pytorch.org/whl/cpu` |
| 免费内网穿透 URL 每次重启都变 | 提交前固定地址，或改用云服务器 |
| 首个请求超时（模型冷启动 ~10s） | 部署后先 `curl /api/health` 预热一次 |
| easyocr 首次运行卡住 | 首次会下载约 100MB OCR 模型，属正常，之后走本地缓存 |
| 服务器内存不足 OOM | 选 4G 内存以上；Gunicorn worker 数控制在 2 |
| 演示时 AI 功能静默降级 | 录屏前必须核对 `/api/health` 的 `nlp_semantic` / `multimodal_ocr` |
